# 🎓 Campus Connect

A web-based campus platform designed to connect students and provide a centralized space for campus interaction and resources.

## 📌 About the Project

Campus Connect is a student-focused web application created to make campus interaction easier and more organized.

The project provides a simple platform where students can access campus-related features through a clean and user-friendly interface.

## ✨ Features

* Student login interface
* Interactive dashboard
* Clean and responsive design
* Simple navigation
* Student-focused campus experience
* Organized frontend structure

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shishi256/campus_connect.git
```

### 2. Open the project

```bash
cd campus_connect
```

### 3. Run the project

Open `login.html` in your web browser.

No additional installation or dependencies are required.
